# Пакет для облачной сессии (Кнопка)

1. Открой облачную сессию, загрузи эту папку целиком (или архив `knopka-handoff.zip`).
2. Для озвучки: создай `audio/` и положи записи (`01-hook.wav` … `06-final.wav`), затем вставь в чат содержимое `prompts/PROMPT-1-video-ozvuchka.md`.
3. Для канала/бренда: вставь содержимое `prompts/PROMPT-2-kanal-brend.md`. Эта задача не требует видео и может идти в отдельной сессии параллельно.

Что внутри: `video/` (скрипты сборки, мои записи экрана без личных диалогов, записи Claude Code, прошлые версии роликов), `cards/` (карусель из 10 карточек, HTML + PNG), `deck/` (презентация, исходники слайдов).
Оригиналы телефонных записей с чужими диалогами сознательно не включены.
